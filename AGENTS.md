# Project rules

- Commit every change you make before handing off a task. Do not leave your own changes uncommitted.
- Stage only files within the task's scope; preserve any pre-existing user changes.
- Use a distinct, descriptive commit message for each changed file or logical folder.
- Run `npm run lint` before committing code changes.
- Do not push or add a remote unless the user provides a repository URL and asks for it.
